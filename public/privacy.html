TRANSPARENCY FIRST

AI code review privacy.

Understand what happens when you submit code for external AI analysis.

What is sent?

When you use AI code review, the source code you submit is sent to the external AI provider configured by the service operator. The provider processes that content under the applicable account terms, settings, and retention policies.

What should I avoid submitting?

Do not submit passwords, API keys, private keys, personal data, customer data, or confidential source code unless you are authorized to share it with the configured provider. Remove secrets and unrelated proprietary content first.

How does this app handle submissions?

  • Submissions are limited to 20,000 characters.
  • The application does not execute submitted code or suggested fixes.
  • AI output is advisory, schema-validated, and may still be incorrect or incomplete.
  • The code-review endpoint does not save submitted code as a review record. Infrastructure/provider logs and retention are separate and depend on the deployment and provider.

Before using this with a team

The service operator should confirm provider retention and data-processing settings, publish any organization-specific privacy terms, set usage budgets, and establish a process for data requests. This page is informational and is not legal advice.
